# Hot Testing Community

Готова чистова статична версія сайту для GitHub Pages. Тут немає Wix, збирача,
Node.js або серверної частини.

## Сторінки

- `/` — головна;
- `/learn/` — навчальні матеріали;
- `/reading-pw-docs-2026/` — повна сторінка серії про документацію Playwright: формат,
  вартість, доступ, програма з 7 модулів і інформація про викладача.

## Публікація на GitHub Pages

1. Закомітьте та відправте зміни до гілки `main`.
2. На GitHub відкрийте **Settings → Pages**.
3. У **Build and deployment** виберіть **Deploy from a branch**, гілку `main` і папку `/ (root)`.
4. Якщо використовуєте домен `www.hottestingcommunity.com`, перейменуйте `CNAME.example` на `CNAME` і налаштуйте DNS за підказками GitHub Pages.

Усі внутрішні посилання відносні, тому сайт працює і на власному домені, і в підпапці GitHub Pages.
