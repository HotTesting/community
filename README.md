# Hot Testing Community

Статичний дім української технічної спільноти: навчання, знайомство зі спільнотою,
події та інформація про автора. Новини й оперативні анонси живуть у Telegram.

HTML, CSS і невеликий необов’язковий JavaScript для мобільного меню та анімації.
Збирача, Wix, серверної частини чи встановлення залежностей не потрібно.

## Сторінки

- `/` — головна;
- `/learn/` — актуальне навчання та згорнутий архів майстер-класів 2024 року;
- `/reading-pw-docs-2026/` — повна сторінка серії про документацію Playwright: формат,
  вартість, доступ, програма з 7 модулів і інформація про викладача.

## Публікація на GitHub Pages

1. Закомітьте та відправте зміни до гілки `main`.
2. На GitHub відкрийте **Settings → Pages**.
3. У **Build and deployment** виберіть **Deploy from a branch**, гілку `main` і папку `/ (root)`.
4. Якщо використовуєте домен `www.hottestingcommunity.com`, перейменуйте `CNAME.example` на `CNAME` і налаштуйте DNS за підказками GitHub Pages.

Усі внутрішні посилання відносні, тому сайт працює і на власному домені, і в підпапці GitHub Pages.

`404.html` самодостатній: він не залежить від відносних шляхів до стилів та зображень,
які могли б зламатися на вкладеній неіснуючій адресі. На домені `hottesting.github.io`
кнопка повернення веде до `/community/`, на власному домені — до `/`.
Якщо назва репозиторію чи власник зміняться, оновіть цю адресу в `404.html`.

## Де оновлювати інформацію

- Основний курс: `reading-pw-docs-2026/index.html`. Короткий опис також є на головній
  та в `learn/index.html`. «60+ відео» — план серії, яка поповнюється.
- Новий курс: додайте окрему папку з `index.html` та картку в `learn/index.html`.
  На головній показуйте актуальну пропозицію, не весь архів.
- Події: сталий блок `#events` на головній; найближчі дати й анонси — у Telegram.
- Чат: `https://t.me/hot_testing`; новини: `https://t.me/hottestingchannel`.
  Посилання задані безпосередньо в HTML і працюють без JavaScript.
- Майбутній перехід у Discord: замініть посилання на чат і його підписи в трьох
  основних HTML-файлах. Посилання на канал новин залиште окремими.
- Дизайн: спільний `assets/styles.css`. Українська кирилиця й латиниця мають локальні
  файли шрифтів Inter та Oswald; їхні ліцензії збережені в `assets/fonts/`.
- Зображення: оптимізовані WebP з наданого бренд-набору та фото спільноти;
  портрет викладача — AVIF. Зовнішніх завантажень для відображення сторінок немає.

## Локальний перегляд

З кореня репозиторію запустіть `python3 -m http.server 4173` і відкрийте
`http://localhost:4173/`. Для публікації цей сервер не потрібен.

## Наступні змістовні доповнення

Найкорисніші матеріали для розвитку: відгуки учасників із дозволом на публікацію,
посилання на благодійні звіти та нові програми курсів. На сайті немає вигаданих
відгуків, дат майбутніх подій або активного запрошення у ще не запущений Discord.
